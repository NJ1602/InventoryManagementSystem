# InventoryManagementSystem
This is an Agentic AI which is created to manage the Inventory. We just need to input the no. of products sold for each SKU A---> J (10 different SKU) and it will automatically calculate the ROP, EOQ, based on the lead times for each of the SKU and email me the flagged items for which the SKU is less than the ROP(based on historic sales)
